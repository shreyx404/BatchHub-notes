§ 06 · Classification I

Classifying Data by Nature — Qualitative vs Quantitative

deck ref · Part I, slides 20–37

How data is classified — by nature and by level of measurement — is foundational: it dictates which mathematical operations are permissible, which charts you can use, and which statistical tests are valid.

Quantitative — discrete vs continuous (crucial for engineers)

DiscreteContinuous
ValuesDistinct, isolated values — gaps between possible valuesAny value within a range/interval — infinitely many values between any two points
OriginYou count itYou measure it with an instrument
Math propertyCountable set (often integers); no "half" a unitReal numbers; precision limited only by sensor quality
ExamplesDefects on a PCB (0, 1, 2 … never 1.54) · packets dropped per second · cars through a toll boothAnalog sensor voltage (3.415 V) · CNC piston diameter (15.0023 mm) · algorithm execution time (0.00421 s)
Distribution toolDiscrete frequency distribution → later PMF (Binomial, Poisson)Grouped / continuous frequency distribution → later PDF (Normal / Gaussian)

Qualitative (categorical) — and the "numbers" trap

Qualitative data represent attributes, labels or qualities — programming languages in a stack (Python, C++, Java), failure modes of a part (fatigue, corrosion, buckling), network security status (secure, vulnerable, compromised). You cannot meaningfully add or average them.

The trapSometimes categories are coded as numbers (Failure Mode 1, Failure Mode 2…). An engineer must recognize that the "average failure mode = 1.5" is completely meaningless.

Thumb rule — test for categorical data (even if it has numbers): if you add these numbers or find their average, does the result tell you anything physical about the system? If no → categorical data, no matter how many numbers are on the screen.
§ 07 · Classification II

Levels of Measurement — Nominal · Ordinal · Interval · Ratio

deck ref · Part I, slides 38–57

The four levels form a staircase of increasing information — each level inherits everything from the one before and adds one new property.

Nominal — qualitative

  • Core meaning: distinct, named categories with no inherent order or ranking. Numbers used as labels carry no numerical value.
  • Permissible operations: counting frequencies, percentages, mode. No addition, subtraction or ordering.
  • Best visualizations: bar charts (any order — alphabetical or by frequency), pie charts.
  • Examples: IDE used (VS Code, Eclipse, IntelliJ, PyCharm) · version-control platform (GitHub, GitLab, Bitbucket) · app category (Education, Finance, Gaming, Health) · sensor type (Temperature, Humidity, Motion, GPS) · IoT protocol (MQTT, CoAP, HTTP, Zigbee) · CPU manufacturer (Intel, AMD, ARM, Apple).

Ordinal — qualitative

  • Core meaning: categories with a natural, meaningful order, but the distance between categories is unknown or unequal.
  • Permissible operations: counting, mode, median & percentiles; frequency distributions. Mean is generally not appropriate (equal intervals cannot be assumed).
  • Best visualizations: ordered bar charts that preserve the natural progression (Poor → Fair → Good → Excellent). Pie charts are poor for ordinal data — a circle destroys the visual linear progression of ranks.
  • Examples: Likert scales · socio-economic status · race finishes (1st, 2nd, 3rd) · software bug severity (Low → Critical) · customer satisfaction · code-review status · project priority · network signal strength · programming skill level · cybersecurity risk level · AI model rating · app-store stars · issue-resolution priority.
Nuance — mean on ordinal data?
  • Statistically safest: median (and mode) — the recommended measures for ordinal data.
  • Real-world practice: the mean is commonly reported for Likert / rating scales (1–5, 1–7) when there are several ordered categories and large samples — it is easy to interpret and compare, but it silently assumes approximately equal spacing, so interpret with caution.
  • Recognized exceptions where mean is accepted: student feedback, app ratings, employee engagement (HR), product reviews, pain-level scores.

Interval — quantitative

  • Core meaning: ordered numerical data where differences (intervals) between values are equal and meaningful, but there is no true zero — zero is just an arbitrary point on the scale.
  • Permissible: addition, subtraction, mean, median, mode, SD. Not permissible: multiplication/division — ratios are meaningless.
  • Best visualizations: histograms, line graphs, box plots.
  • Classic examples: temperature in °C (0° is not "no temperature") · °F · IQ scores (120 is not twice 60) · SAT scores · GRE Verbal (130–170) · calendar years (Year 0 is arbitrary) · time of day · elevation vs mean sea level (0 m = sea level, negatives exist) · credit score (300–850) · t/z scores in statistics (0 = the reference point, not absence).
Why "zero is arbitrary"A true zero means complete absence of the quantity: weight 0 kg = no weight; distance 0 m = no distance. For standardized tests, a score of 0 (if it even existed) would not mean "no knowledge" — the scale is a reporting convention. Hence 20 °C is not twice as hot as 10 °C; IQ 140 is not twice IQ 70; the year 2000 is not twice as late as the year 1000.

GRE worked illustration (130–170): 150 − 145 = 5 and 155 − 150 = 5 → equal differences represent equal differences in performance. But 150 is not "twice as good" as 75 — the scale doesn't even contain 0.

Ratio — quantitative

  • Core meaning: ordered numerical data with equal intervals and a true, absolute zero (zero = complete absence of the property).
  • Permissible: all arithmetic — +, −, ×, ÷ — and all statistics: mean, median, mode, ratios.
  • Best visualizations: histograms, scatter plots, box plots, line graphs.
  • Examples: height, weight, distance, age, salary, time, raw exam marks (45/100).

Interval vs Ratio — the two quick tests

TestQuestionIntervalRatio
The "Zero" testDoes zero mean none?No — 0 °F just means very cold, not "no weather"Yes — $0 in the bank = no money
The ratio testIs "twice as much" meaningful?No — 100 °F is not twice as hot as 50 °FYes — a 40-year-old is twice as old as a 20-year-old
Marks vs scores — exam favouriteRaw marks (45/100) → ratio (0 = no marks, ratios meaningful). Standardized scores (GRE, GMAT, TOEFL, IQ) → interval (equal differences meaningful, but no true zero, so "twice as capable" is invalid).

Qualitative vs quantitative summary. Nominal & ordinal (qualitative) describe qualities — you cannot average words, so you are limited to non-parametric statistics, frequency tables and proportion charts (bar, pie). Interval & ratio (quantitative) describe measurable quantities — parametric statistics and distribution charts (histogram, box plot, line, scatter) apply.

Frequency Distribution — Concept & Purpose

deck ref · Part I, slides 65–72

Think of it as data compression for engineers — turning a massive, chaotic stream of sensor inputs or log entries into a clean, structured matrix.

Definition

A frequency distribution is an organized way to show how often different values occur in a dataset. Instead of a chaotic list of raw numbers, the grouped data lets you instantly see patterns, trends and outliers. Analogy: taking a messy pile of clothes and sorting them into neat stacks by colour.

  • Frequency tables — display the number of occurrences of each value or characteristic.
  • Frequency graphs — histograms and bar charts plot frequencies as columns; the Y-axis carries the frequency count, the X-axis the variable being measured. Distributions may show absolute frequencies or relative frequencies (proportions / percentages).

§ 12 · Storage

Discrete vs Continuous Metrics — Gauges vs Pre-Binned Histograms

deck ref · Part I, slides 88–93

Understanding the metric's data type dictates your storage choices, the applicable mathematics, and your monitoring dashboards.

Gauge
Stores the current instantaneous value, overwriting the previous one on every scrape. E.g., current active users: active_users = 2843 → one minute later active_users = 2910 (the 2843 is gone). Gauges suit discrete instantaneous counts (CPU %, memory GB, disk %, active users).
Pre-binned histogram
Stores a frequency distribution of values. The ranges (bins / buckets) are decided before the data arrives; each incoming value increments exactly one bucket's count. Ideal for continuous measurements such as API response times — storing every individual value would be too expensive.
Categorize: (a) instantaneous number of current active users on a streaming server; (b) API response time in precise decimal milliseconds — discrete or continuous, gauge or histogram?
(a) Current active users — discrete (you cannot have a fraction of a user; a countable integer space) → store as a gauge (instantaneous value, overwritten minute by minute).
(b) API response time — continuous (infinitely divisible real decimals) → store as a pre-binned histogram (groups continuous values into pre-defined buckets, preventing high storage overhead).
§ 13 · Advanced columns

Relative & Cumulative Frequencies

deck ref · Part I, slides 94–99

Raw counts (f) alone are not enough: if a server drops 500 packets, is that bad? If total sent was 1,000 → catastrophic (50%); if 1,000,000 → negligible (0.05%). Engineers transform raw frequencies to serve risk assessment, SLA compliance and reliability analysis.

Relative frequency Relative Frequency = fn   (f = frequency of the class · n = total data points)
  • The bridge to probability: relative frequency is the empirical probability of an event. If an ML model fails on 200 of 10,000 images in a lighting bin, the relative frequency of failure = 0.02 → future failure probability under similar conditions ≈ 2%.
  • The guardrail: the sum of all relative frequencies must equal exactly 1.00 (100%).

Mini example (grades, n = 10): A: 2 students, B: 5, C: 3 → RF = 0.20, 0.50, 0.30. If you draw one name blindly from a hat, P(B-student) = 0.50. Relative frequency is the real-world shorthand for probability.

Cumulative frequency — two directions

"Less than" CF (<)
Running total built top → bottom; tracks observations falling below the upper boundary of each class. Use: quality control & safety margins — "how many drives failed before 2,000 hours?", "what % of requests finish under 50 ms?" (SLA).
"More than" CF (>)
Built by subtracting from n (or summing bottom → top); tracks observations above the lower boundary of each class. Use: reliability & lifespan — "how many beams withstand a load greater than 50 kN?"
Relative cumulative frequency
CF expressed as a percentage: rCF = (CF / n) × 100. This is what lets you compute percentiles — e.g., the 99th-percentile response time P₉₉, the standard software performance metric.

§ 14 · Construction

Building a Grouped Distribution

deck ref · Part I, slides 100–106

1 · Class intervals (bins)

A class interval is a subset of the data's total range. Bins must be mutually exclusive (no data point fits into two bins) and collectively exhaustive (every data point fits somewhere).

2 · Class limits vs class boundaries

Class limits (stated limits)
The values you write in the table for readability; they usually have gaps between classes (10–19, 20–29, 30–39).
Class boundaries (true limits)
The mathematical boundaries that eliminate the gaps, needed because continuous data can land between stated limits — if a sensor logs 19.6, stated limits leave it stranded. Boundaries split the difference between adjacent limits.
Class boundary Boundary = upper limit of one class + lower limit of next class2    e.g. 19 + 202 = 19.5

3 · How many bins? — Sturges' rule

Sturges' rule · number of bins k = 1 + 3.322 · log₁₀(n)    → round k to the nearest whole integer

Too few bins (e.g., 2) over-compresses and hides the pattern; too many (e.g., 100) leaves a flat, chaotic wall. Sturges gives the statistical guardrail.

Class width w = Maximum value − Minimum valuek    → always round up to a convenient number matching the data's precision
An IoT smart-city gateway captures n = 100 raw air-quality entries. Using Sturges' rule, how many bins?
k = 1 + 3.322·log₁₀(100) = 1 + 3.322(2) = 7.644 → ≈ 8 bins.

§ 16 · Inference preview

Population vs Sample

deck ref · Part I, slides 109–110

Population
The complete set of all elements under study (N). Its summaries are parameters (μ, σ, p) — usually unknown.
Sample
A subset (n) selected from the population, actually measured. Its summaries are statistics (x̄, s, p̂) — computed, and used to estimate parameters.
An airline claims <5% of its flights from Mumbai depart late. From a sample of 100 flights, 7 were late. Identify the population, the sample, the observation — and is 7% a parameter or a statistic?
Population: all flights departing from Mumbai airport (N = very large).
Sample: the 100 observed flights (n = 100).
Observation / statistic: 7 flights departing late → the 7% figure comes from the sample, so it is a statistic, not a parameter. (A parameter would describe all Mumbai flights.)

§ 19 · The core rule

Data Types Dictate Chart Selection

deck ref · Part II, slides 16–21

You cannot choose a chart because it "looks nice". The nature of your data and its level of measurement strictly dictate which charts are mathematically valid — the wrong chart risks misrepresenting the data or invalidating the analysis.

  • Categorical / qualitative data (nominal, ordinal) = labels, groups, qualities. No mathematical averages on words → visualizations must focus on counting frequencies or showing proportions.
  • Numerical / quantitative data (interval, ratio) = measurable quantities → visualizations must focus on distribution, spread and continuous nature of the numbers.
Logic behind each branch
  • Nominal (blood types, brand preference): no natural order → bars may be arranged alphabetically or by frequency; pie shows proportions.
  • Ordinal (satisfaction: Poor → Excellent): built-in hierarchy → bars must display the natural progression. A pie is generally poor for ordinal data — a circle destroys the linear progression of ranks.
  • Discrete (children per household: 0, 1, 2, 3 …): no household has 2.4 children → distinct isolated steps → visualization should show spaces between values (bar chart / dot plot).
  • Continuous (salaries, exam scores, run times): can take any value in an interval → group into continuous bins; histogram bars must touch to represent the unbroken numerical scale.

Box Plots (Box-and-Whisker Plots)

deck ref · Part II, slides 53–68

A box plot displays the five-number summary — minimum, first quartile (Q1), median, third quartile (Q3), maximum — in one compact graphic.

Construction

  1. Scale and label an axis that fits the five-number summary.
  2. Draw a box from Q1 to Q3 with a vertical line through the median.
  3. Draw whiskers from Q1 to the minimum and from Q3 to the maximum.

The 10 concepts, in order: Q1 → Median → Q3 → IQR → Box → Whiskers → Fences → Outliers → Skewness → Spread.

Core box-plot formulas IQR = Q3 − Q1   ·   Lower Fence = Q1 − 1.5·(IQR)   ·   Upper Fence = Q3 + 1.5·(IQR)   ·   Outside fences ⇒ outlier
  • Q1 → Median → Q3 describe the centre and position of the data.
  • IQR = Q3 − Q1 describes the spread of the middle 50%.
  • Values plotted beyond the fences are outliers; box + whiskers give a visual summary of the whole distribution.
  • Median tells the centre, IQR the consistency, whiskers the spread, outliers the unusual observations — and comparing complete box plots supports better engineering decisions.

General interpretation guide

FeatureQuestionReading
MedianWhere is the typical value?Higher median → generally higher typical values; lower median → lower typical values.
IQRIs the middle 50% tight or loose?Small IQR → consistent data · large IQR → variable data.
Box sizeShort or long box (Q1→Q3)?Short box → low variability (predictable process); long box → high variability.
OutliersPresent? How many? Which side?Few outliers → occasional unusual observations; many → the process may require investigation. An outlier does not automatically mean an error.
WhiskersLong or short? Roughly equal?Long whiskers → greater variability; short → less; equal whiskers → roughly symmetric.

Skewness signs in a box plot

Tukey's 1977 summary (theory box)

  • First described by Tukey (1977); a vertical/horizontal rectangle (box) whose ends correspond to the quartiles (75th and 25th percentiles) — the middle 50% of observations. Box length indicates variability; the inner line is the median (sometimes a plus sign).
  • Median position: closer to the upper quartile → negatively skewed; nearer the lower quartile → positively skewed.
  • Whiskers extend up to 1.5 × IQR from the box ends; the whisker end is the inner fence — any value beyond is an outlier. If the distribution is symmetrical, whiskers are of equal length; where data are sparse on one side, that whisker is short.
  • Outer fence (usually unmarked) at 3 × IQR. Rationale: ≈ 95% of observations fall within 1.5 × IQR, and ≈ 99% within 3 × IQR.
Statistical vs practical (engineering) significanceThey are different. Example — a manufactured part has target diameter 50 mm; an actual diameter of 50.15 mm may not be a statistical outlier, yet it can still violate engineering specifications. A box plot can only tell you the first half of that story.

Worked comparison — two network servers

Two servers, A and B, are tested for network latency. Five-number summaries: A — min 18, Q1 22, median 25, Q3 29, max 35 ms. B — min 15, Q1 20, median 30, Q3 42, max 70 ms.

  1. IQR: A = 29 − 22 = 7 ms; B = 42 − 20 = 22 ms.
  2. Typical latency (median): A = 25 ms < B = 30 ms → A has the lower typical latency.
  3. Variability: A's smaller IQR means its middle 50% is more closely grouped → A is considerably more consistent.
  4. Engineering decision: B has a higher median, much larger IQR, larger overall range, and a maximum of 70 ms; A has lower median, smaller IQR, smaller range, more predictable performance → recommend Server A for low and stable latency.
LessonThis is why an engineer should never compare systems using only the average or median — variability is also a decision variable.
Exercise — a web server's 100-request response times give: min = 80, Q1 = 100, median = 120, Q3 = 140, max = 180 ms. Find the median, the IQR, what the IQR tells you, and the typical value.
Median = 120 ms. IQR = 140 − 100 = 40 ms. The IQR says the middle 50% of requests range over 40 ms (100 → 140) — the "typical" spread of ordinary requests. The value representing typical response time is the median, 120 ms. Bonus: fences = 100 − 60 = 40 and 140 + 60 = 200 → no outliers (80 > 40, 180 < 200); median sits centred in the box with a slightly longer upper whisker → roughly symmetric with a mild positive skew.

Measures of Central Tendency

deck ref · Part III, slides 9–13

Central tendencies are numerical values that represent the middle or typical value of a dataset. Also called averages, they summarize the entire data, making the overall pattern or behaviour easy to grasp.

§ 26 · Average № 1

The Mean

Mean — population / sample μ = Σ xᵢN   ·   x̄ = Σ xᵢn   ·   grouped: x̄ = Σ fᵢ·mᵢΣ fᵢ

xᵢ = observations · N = population size · n = sample size · fᵢ = class frequency · mᵢ = class midpoint.

  • Properties: uses every value; unique; the point about which deviations balance — Σ(xᵢ − x̄) = 0; the sampling-stable average (varies least from sample to sample).
  • Weakness: highly sensitive to outliers and extreme values — a single large observation can drag it far from the "typical" value.

Mini worked example — server response times (ms): 4, 8, 6, 2, 10 → Σx = 30 → x̄ = 30/5 = 6 ms. Check the balance property: deviations −2, +2, 0, −4, +4 sum to 0 ✓. (Grouped-data example: the latency table of § 14 → x̄ = 44 ms.)

MeritsDemerits
Uses all data · rigidly defined · sampling-stable · basis for variance/SD and most inferenceDistorted by outliers · impossible for nominal/ordinal data · may be a value that doesn't occur in the data · misleading for skewed data
§ 27 · Average № 2

The Median

Median — position in sorted data odd n: value at position n + 12  ·  even n: average of values at positions n2 and n2 + 1  ·  grouped: Med = L + n/2 − CFf·h
  • A positional average — the 50th percentile; it depends on rank, not magnitude, so it needs only ordinal information.
  • Robust: unaffected by extreme values or outliers (change the largest value to a million and the median doesn't move).
  • Preferred for skewed datasets or those containing outliers; suitable for ordinal and numerical data.

Worked (odd n): 7 response times sorted — 12, 15, 18, 21, 25, 30, 44 → position (7+1)/2 = 4 → median = 21 ms.
Worked (even n): the 10 salaries of § 35 → positions 5 and 6 hold 38 and 40 → median = 39 (while the mean is 55.5 — the founder's salary pulls the mean but not the median).

The Mode

Mode — grouped data Mode = L + Δ₁Δ₁ + Δ₂·h    Δ₁ = f₁ − f₀  ·  Δ₂ = f₁ − f₂

L = lower boundary of the modal class · f₁ = its frequency · f₀ = frequency of the preceding class · f₂ = frequency of the succeeding class · h = class width.

  • The most frequently occurring value; a dataset can be unimodal (one mode), bimodal (two — e.g., the shoe sizes of § 11: 7 and 8), multimodal, or have no mode (all values unique — e.g., the salaries of § 35).
  • The only average usable for nominal (categorical) data — "most common failure mode", "most-used IDE". Ideal for categorical data or numerical data with repeating values → suitable for qualitative analysis.
  • Unaffected by outliers (an extreme value is, by definition, rare).

Worked (grouped): modal class of § 14 is 39.5–48.5 (f₁ = 6, f₀ = 4, f₂ = 4, h = 9) → Mode = 39.5 + (2/4)·9 = 44 ms.

  • Negatively skewed: mean is smaller than the median.

Measures of Dispersion — Overview & the Range

deck ref · Part III, slides 20–24

Dispersion is the degree to which data values are spread out or scattered around an average (mean or median). A measure of central tendency describes the general level of magnitude but fails to give any idea of the variability of observations.

Dispersion tells us about the variability or consistency within the data — whether values are closely grouped or widely spread — and lets us compare the reliability/uniformity of different datasets.

FamilyMeasuresNature
Absolute measuresRange · Interquartile range (IQR) · Variance · Standard deviationCarry the data's units; describe one dataset's spread
Relative measuresCoefficient of variation (CV) · coefficient of quartile deviationUnitless ratios; compare variability across variables with different units or means

The range

Range Range = Maximum observation − Minimum observation
  • One of the most common measures of dispersion; it has the same unit as the data variable.
  • Limitations: (1) heavily impacted by outliers and extreme values; (2) considers only the maximum and minimum — it uses no information from any other observation.
  • Worked: battery temperatures (§ 9): 45.0 − 37.0 = 8.0 °C; salaries (§ 35): 200 − 25 = 175 (₹ '000) — entirely created by the founder's outlier.
§ 32 · Spread II

Standard Deviation & Variance

deck ref · Part III, slides 25–29

Standard deviation (SD)
A measure of how much the data is dispersed from its mean. A high SD implies values are more spread out from the mean. Denoted SD, Greek σ (population) or Latin s (sample). Its unit is the same as the variable's unit. It is impacted by extreme values/outliers, and it can be zero — if and only if every value is identical.
Variance
The square of the standard deviation. Always non-negative; its unit is squared, making it less intuitive. SD is preferred over variance because SD (same units) can be compared directly with the mean. Variance nonetheless plays a central role in statistics — it underlies ANOVA, R², hypothesis testing and statistical inference.
Population (divide by N) σ² = Σ (xᵢ − μ)²N   ·   σ = √σ²
Sample (divide by n − 1) s² = Σ (xᵢ − x̄)²n − 1   ·   s = √s²   ·   computational: s² = Σxᵢ² − n·x̄²n − 1
Why n − 1? (Bessel's correction)Sample deviations are measured from x̄ — a centre fitted to the sample itself — which makes Σ(xᵢ−x̄)² systematically too small as an estimate of the population's spread around μ. One degree of freedom is "used up" estimating the mean; dividing by n − 1 instead of n corrects the bias. Rule: population data → N; sample data → n − 1.

Coefficient of Variation (CV / CoV)

deck ref · Part III, slides 30–38

Coefficient of variation — relative variability CV = σμ × 100%     (population)   ·   CV = sx̄ × 100%     (sample)
  • A measure of relative variability — variation relative to the mean, expressed as a percentage instead of original units.
  • Unitless (a ratio of SD to mean) → allows comparison of variability between two variables or two tests even when their units differ.
  • Valid only for ratio-scale variables — it needs a meaningful mean and a meaningful ratio (see the trap below).

Interpreting CV (rule of thumb — context dependent)

CVReading
≤ 10%Low variability — very consistent process
10–20%Moderate variability
20–30%High variability — investigate
> 30%Very high variability relative to the mean

Why do we need CV? — the two-machines story

Two machines manufacture screws. Machine A: SD = 5 (around mean 100). Machine B: SD = 20 (around mean 1000). Judging by SD alone, A looks better. But relative to their averages: 5 is 5% of 100, while 20 is only 2% of 1000 → Machine B is actually more consistent. That is exactly what CV measures.

Worked — two microservices (performance-test suite, 24-hour cycle)

  • Microservice X: μ = 100 ms, σ = 5 ms → CV = (5/100)×100 = 5%
  • Microservice Y: μ = 1,000 ms, σ = 20 ms → CV = (20/1000)×100 = 2%
  • Conclusion: Microservice Y performs more consistently. Even though its absolute SD is higher (20 vs 5), its variation relative to its operational baseline is significantly lower (2% vs 5%).

Worked — retail customers: Age vs Spend

Age: mean 30 years, SD 6. Spend: mean ₹6,000, SD ₹1,000. From the absolute SDs you cannot say which varies more — the units differ (years vs rupees). Thought experiment: express age in days → SD becomes 6 × 365 = 2,190 days, yet nothing real changed — proving absolute SD is unit-dependent.

  • CV(Age) = 6/30 = 0.20 (20%)
  • CV(Spend) = 1000/6000 = 0.167 (16.7%)
  • CV of Spend < CV of Age → variability in Age is greater than in Spend.
Bonus insight — CV is unit-invariantIn days, Age's CV = 2190/10950 = 0.20 — identical. Switching units cannot change a relative measure. That is precisely why CV (and only CV) permits cross-unit comparison.
Why ratio-scale only?Interval scales have an arbitrary zero, so both the mean and any ratio are arbitrary — the CV of temperature in °C differs from its CV in °F for the same data! Ratios (σ/μ) are only meaningful when 0 means "none" — i.e., on the ratio scale. CV is also undefined/meaningless when the mean is zero or negative.

The median is the appropriate "typical" salary; the mean, SD (≈ 52k), range (175k) and CV (≈ 93%) are all inflated by that single point. The IQR (21k) is the honest summary of ordinary spread: the middle 50% of employees earn within roughly ₹21k of each other. Recommendation: report median ± IQR, and treat 200 as a flagged outlier (real, but not representative).

Cumulative frequency
Running total of frequencies — "less than" (below upper boundaries) or "more than" (above lower boundaries).
Descriptive statistics
Summarizing and presenting known data via graphs and numerical measures.
Discrete data
Counted values from a countable set with gaps between possibilities (defects, packets/s).
Dispersion
The degree to which values scatter around an average (range, IQR, variance, SD, CV).
Empirical relation
Mode ≈ 3·Median − 2·Mean, for moderately skewed unimodal data.
Fence
Outlier boundary: inner at 1.5·IQR beyond the quartiles; outer at 3·IQR (≈95% / ≈99% of data inside).

Minimum, Q1, median, Q3, maximum.

Organized tabling of how often each value/class occurs.
Gauge
Monitoring primitive storing the current instantaneous value, overwritten on each scrape.
Histogram
Continuous-data distribution chart; touching bars, bins on the x-axis, area ∝ frequency.
Inferential statistics
Using sample statistics plus probability theory to estimate parameters and test hypotheses.
Interquartile range
IQR = Q3 − Q1; the spread of the middle 50% of observations.
Mean
Arithmetic average Σxᵢ/n; uses all values; outlier-sensitive; needs interval/ratio data.

Ogive
Graph of cumulative frequency; less-than rises to 100%, more-than falls to 0%; cross at median.

Value beyond a fence; unusual but not automatically an error (see practical significance).
Parameter
Numerical summary of a population (μ, σ, p) — generally unknown, estimated by statistics.

Value below which a given % of observations fall; obtained from relative cumulative frequency (P₉₉).

The complete set of N elements under study.
Relative frequency
f/n — the empirical probability of a class; all values sum to 1.
Sample
A subset of n elements actually measured, used to infer about the population.

§ 38 · Revision

Exam Traps & Rapid Revision

The 20 classic traps

  1. Numbers as labels — failure modes coded 1, 2, 3 are nominal; an "average failure mode of 1.5" is meaningless. Apply the thumb rule: does averaging tell you anything physical?
  2. "Twice as" on interval data — never valid: 20 °C ≯ 2 × 10 °C; IQ 140 ≯ 2 × IQ 70; year 2000 ≯ 2 × year 1000. Ratios require a true zero (ratio scale).
  3. Raw marks vs standardized scores — 45/100 is ratio; GRE/IQ/SAT are interval.
  4. Pie for ordinal data — a circle destroys the rank progression; use ordered bars.
  5. Bars vs histogram gaps — discrete/categorical → gaps between bars; continuous → bars touch.
  6. Histogram area — with unequal bin widths it is the area, not the height, that represents frequency.
  7. Overlapping classes ("60–70, 70–80") are invalid; a value of exactly 70 is ambiguous. Use true boundaries.
  8. Boundary routing — 19.6 falls up into the 19.5–29.5 class (boundary = (19+20)/2 = 19.5).
  9. Sturges rounding — round k to the nearest integer (7.644 → 8); round width up (8.6 → 9).
  10. Relative frequency guardrail — ΣRF must equal exactly 1.00; use it as an arithmetic check.
  11. CF directions — CF< attaches to upper boundaries; CF> attaches to lower boundaries; they cross at the median.
  12. Mean on ordinal data — the median is statistically safest; the mean is only a convention on large Likert samples (assumes equal spacing).
  13. Units — SD carries the data's units; variance carries squared units; CV carries none.
  14. N vs n − 1 — population → N; sample → n − 1 (Bessel's correction; one degree of freedom used estimating the mean).
  15. Zero cases — SD = 0 ⇔ all values identical; variance is never negative; skew = 0 ⇔ symmetric.
  16. Comparing SDs across units or very different means — meaningless; compare CVs (machines 5% vs 2%; microservices; Age vs Spend).
  17. CV's domain — ratio scale only; undefined/meaningless for interval scales (°C vs °F give different CVs!) and for zero/negative means.
  18. Mean chases the tail — positive skew: mean > median > mode; negative: mean < median < mode. The mode never leaves the peak.
  19. Outlier ≠ error, and in-spec ≠ okay — a 50.15 mm part may not be a statistical outlier yet still fail engineering specs (practical significance).
  20. Parameter vs statistic — the airline's 7% from 100 sampled flights is a statistic; only a figure covering all Mumbai flights would be a parameter.

Part I in 60 seconds

Data by nature (qualitative = labels; quantitative = discrete counted / continuous measured) and by level (nominal → ordinal → interval → ratio; each adds order → equal spacing → true zero). Raw stream → array (min/max/range) → frequency distribution (data value + tally + f; ungrouped for discrete, grouped for continuous; classes never overlap; boundaries at .5 via the midpoint rule). Bins: Sturges k = 1 + 3.322 log₁₀n; width = range/k rounded up. Extended columns: RF = f/n (→ empirical probability, Σ = 1), CF</CF> (→ thresholds, SLA, reliability), rCF (→ percentiles, P₉₉); ogives cross at the median. Storage: gauges for instantaneous discrete metrics, pre-binned histograms for continuous ones. Population (N, μ, σ — parameters) vs sample (n, x̄, s — statistics).

Part II in 60 seconds

The brain reads pictures faster than numbers → visualize first. Anscombe's quartet: four datasets, identical mean/variance/r/regression (x̄=9, ȳ=7.5, r≈0.816, ŷ=3+0.5x), completely different shapes — numbers can hide structure. Chart choice is dictated by measurement level: nominal → bar/pie; ordinal → ordered bar; discrete → bar/dot with gaps; continuous → histogram/box/line with touching bars. Histogram: bins, touching bars, area = frequency, checklist = peak → spread → shape → multiple peaks → gaps → unusual values → requirements; right-skew = long high-value tail. Box plot: five numbers; IQR = Q3 − Q1; fences = quartiles ± 1.5·IQR; whiskers to the most extreme in-fence values; skew signs (median near Q1 + long upper whisker = right skew). Compare systems on median and IQR — never the average alone. Beware truncated axes, cherry-picking, 3D effects, cluttered dashboards, and missing labels.

Part III in 60 seconds

Averages: mean (uses everything, outlier-sensitive, interval+), median (positional, robust, ordinal+), mode (frequency, nominal+). Shapes: symmetric → all three equal; positive skew → mean > median > mode; negative → reversed; empirical Mode ≈ 3·Med − 2·Mean. Dispersion: range (max − min; ignores the middle), variance (squared units; feeds ANOVA/R²/testing), SD (data units; "average deviation from the mean"; σ uses N, s uses n − 1), CV = SD/mean × 100 (unitless, ratio-scale only, for cross-unit/cross-scale comparison — Service Y at 2% beats Service X at 5% despite the larger absolute SD). Dispersion = how much spread; skewness = which way lopsided.

Classify fully (nature + level): (a) packets dropped per second · (b) CPU temperature in °C · (c) bug severity Low/Medium/High/Critical · (d) MAC address
(a) Quantitative, discrete, ratio (counts, true zero). (b) Quantitative, continuous, interval (no true zero — 0 °C ≠ no temperature). (c) Qualitative, ordinal (ranked, unequal spacing). (d) Qualitative, nominal — a numeric string used purely as a label; averaging MAC addresses is meaningless.
Using Sturges' rule, how many bins for n = 200 observations? And what is the first step after finding k?
k = 1 + 3.322·log₁₀(200) = 1 + 3.322(2.301) = 8.64 → 9 bins. Next: class width w = (max − min)/k, rounded up to a convenient value; then build non-overlapping classes with true boundaries.
For the data 3, 5, 7, 9, 11, 13 find the mean, median, sample SD, and population SD.
Mean = 48/6 = 8. Median = (7+9)/2 = 8. Deviations: ±5, ±3, ±1 → Σ(x−x̄)² = 70. Sample: s² = 70/5 = 14 → s = 3.74. Population: σ² = 70/6 = 11.67 → σ = 3.42. (Same data, two divisors — always state which convention you used.)
A dataset has mean 60, median 50, s = 15. Comment on the shape, estimate the mode, and quantify the skew.
Mean > median → positive (right) skew. Pearson: Sk = 3(60−50)/15 = +2 → strongly skewed. Mode ≈ 3(50) − 2(60) = 30, consistent with mode < median < mean.
A box plot has Q1 = 25, Q3 = 45, and a maximum of 90. Is 90 an outlier?
IQR = 20. Fences: LF = 25 − 30 = −5; UF = 45 + 30 = 75. Since 90 > 75 → yes, 90 is an outlier; the upper whisker would end at the largest value ≤ 75.
Machine A: x̄ = 50 units, s = 5. Machine B: x̄ = 200 units, s = 10. Which is more consistent, and why is judging by SD alone wrong here?
CV(A) = 5/50 = 10%; CV(B) = 10/200 = 5% → B is more consistent. B's absolute SD is larger, but its spread relative to its mean is half of A's. When means differ substantially (or units differ), only the CV is a fair comparison — and CV is only valid because both are ratio-scale.
Explain in two lines why the sample variance divides by n − 1.
Deviations are taken from x̄ — a centre fitted to the sample itself — which makes Σ(xᵢ−x̄)² systematically too small as an estimate of the population spread (one degree of freedom is consumed estimating μ). Dividing by n − 1 instead of n corrects this bias (Bessel's correction).
State three situations where the CV must not be used.
(1) Interval-scale data — zero is arbitrary, so σ/μ changes with the unit (°C vs °F). (2) A zero or negative mean — the ratio becomes meaningless/undefined. (3) Nominal/ordinal data — no meaningful mean or SD exists in the first place.
Give the three differences between a bar diagram and a histogram.
(1) Bar diagram has gaps between bars (distinct categories); histogram bars touch (continuous variable). (2) Bar widths are equal; histogram bar widths vary with the class interval. (3) In a bar diagram the height encodes the value; in a histogram the area of each bar corresponds to the frequency.
What is Anscombe's quartet and the lesson it teaches?
Four datasets (Anscombe, 1973) with identical summary statistics — x̄ = 9.0, ȳ = 7.5, sample variances 11.0 and ≈4.12, r ≈ 0.816, and the same regression line ŷ = 3 + 0.5x — yet their plots are entirely different: (I) linear, (II) a smooth curve, (III) linear with one y-outlier, (IV) mostly constant x with one x-outlier. Lesson: numerical summaries can hide critical structure — always visualize data before analyzing it.
Bonus numeric — data: 2, 4, 4, 5, 7, 9. Find mean, median, mode and the shape.
Mean = 31/6 ≈ 5.17; median = (4+5)/2 = 4.5; mode = 4. Mean > median > mode → right (positively) skewed.
