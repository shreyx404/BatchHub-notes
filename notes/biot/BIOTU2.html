01

Basics of the Microprocessor

What a microprocessor is, what it actually does all day, and how it talks to memory and the outside world.

Key Fact — Definition

A microprocessor is a small electronic device that contains all the functions of a computer's Central Processing Unit (CPU) fabricated on a single Integrated Circuit (IC). It fetches instructions from memory, decodes them, executes them, and controls the flow of data. Informally: the brain of the computer — also called simply a processor or CPU.

Understanding the definition

  • Single chip: a microprocessor is a computer processor mounted on one IC — all processor functions (ALU, registers, control) live on that single piece of silicon.
  • Arithmetic & logic engine: it performs the arithmetic and logical operations of the computer and is responsible for executing instructions and controlling the flow of data.
  • Billions of transistors: modern microprocessors are made of billions of transistors organised into functional units — registers, the arithmetic logic unit (ALU), and input/output interfaces.
  • Design goals: microprocessors are designed to be fast, energy-efficient and versatile, and power everything from personal computers to supercomputers.
  • The working loop: input the instructions from memory → decode them → process them → produce the output.

The three basic tasks

While processing information, a microprocessor repeatedly performs three basic tasks. This list is a favourite short-answer question — learn it verbatim:

  • 1 · Calculate — perform basic calculations using the ALU: addition, subtraction, multiplication, division, increment, decrement, comparisons.
  • 2 · Move data — transfer data from one location to another: memory ↔ registers ↔ I/O ports.
  • 3 · Track the program — maintain the Program Counter (PC), a pointer that stores the address of the next instruction; the processor keeps track of the PC and performs instructions in sequence accordingly.

Block diagram of a microprocessor

The CPU itself is built from three cooperating units — the register array (temporary storage: accumulator, general-purpose registers, PC, SP, flags), the control unit (decodes instructions, generates timing and control signals) and the ALU (the calculation engine). It reaches the outside world only through three buses:

The three buses — know them cold

  • Address bus — unidirectional (CPU → memory): carries the location where data is to be read from or stored. The 8085's address bus is 16 bits wide → 2¹⁶ = 64 KB of addressable memory.
  • Data bus — bidirectional: carries the actual data being stored or retrieved. 8 bits wide on the 8085.
  • Control bus: carries commands and timing — RD, WR, ALE, IO/M, interrupt lines, clock — synchronising every participant.
Exam Tip

A guaranteed 2-mark question: "What are the three basic functions of a microprocessor?" Answer with the trio — (i) ALU calculations, (ii) data movement, (iii) PC tracking & sequential execution. Also be ready to define it in one line: "CPU on a single integrated circuit."

02

Evolution of the Microprocessor

From a 4-bit calculator chip in 1971 to billion-transistor multi-core processors — the story examiners love to ask as a timeline.

In 1971, Intel introduced the first commercial microprocessor — the Intel 4004. Its capacity was just 4 bits: it could perform only addition and subtraction on 4-bit numbers at a time. From that modest beginning, each generation roughly doubled the word width and multiplied the transistor count, giving us the processor family tree below.

1971Intel 40044-BIT

The first commercial microprocessor. Able to perform only addition/subtraction operations on 4 bits at once. Around 2,300 transistors — less than a modern processor uses for a single cache cell block.

1976Intel 80858-BIT

The classic 8-bit teaching processor — the star of Chapters 03 and 04. Complete CPU (ALU, registers, control) on one chip, +5 V supply, 40-pin package.

1976Intel 808616-BIT

16-bit architecture and the founding member of the x86 dynasty that still powers PCs. Its sibling the 8088 (16-bit CPU with an 8-bit data bus) ran the original IBM PC; the 8087 was its numeric coprocessor companion for floating-point maths.

1982Intel 8028616-BIT

16-bit processor with protected-mode memory management — the engine of the IBM PC/AT generation.

1985Intel 8038632-BIT

The first 32-bit x86 — flat 32-bit addressing, hardware multitasking, and the architecture that carried desktop computing into the 1990s.

1989Intel 8048632-BIT

Deeply pipelined 32-bit design with on-chip cache and (in the DX variant) a built-in math coprocessor — dramatically faster per clock.

1997 → 2000Pentium II · III · IV32-BIT

The superscalar multimedia era: multiple instructions in flight per cycle, MMX/SSE vector units, and clock speeds climbing past a gigahertz.

NowCore 2 Duo · Dual-Core · Quad-Core64-BIT · MULTI-CORE

Instead of just one faster core, multiple full CPU cores share a single chip — letting the processor do genuinely parallel work for modern multitasking workloads.

Memory Aid

Remember the spine of the story: 4 → 8 → 16 → 32 → 64 bits, keyed by chips 4004 → 8085 → 8086 → 80386 → multi-core. Anchor years: 1971 (4004) and 1976 (8085 and 8086, as per the syllabus).

Extra

Beyond the syllabus headlines, Intel's 8-bit path ran 8008 (1972) → 8080 (1974) → 8085 (1976). Mentioning the 8008/8080 in an answer shows depth — but always keep 4004, 8085 and 8086 as your headline entries.

03

Architecture of the 8085

Register by register, block by block — the complete internal anatomy of Intel's 8-bit classic.

The 8085 is an 8-bit microprocessor developed by Intel in the mid-1970s. Before diving in, fix these headline numbers in your head — they frame every 8085 question:

  • 8-bit data bus (bidirectional) · 16-bit address bus (unidirectional) → 64 KB address space
  • 40-pin DIP package, single +5 V supply (VCC / VSS)
  • Crystal connected at X1–X2 sets the clock; the frequency is internally divided by 2
  • 5 hardware interrupts (TRAP, RST 7.5, RST 6.5, RST 5.5, INTR) and 5 flags (S, Z, AC, P, CY)
  • Register structure: Accumulator, general-purpose registers, program counter, stack pointer, instruction register, flag register (+ temporary register)

The register set

Accumulator (A) — 8 bits

An 8-bit register connected to the ALU and the internal data bus. It is the star of the register set: in almost every operation, one operand sits in the accumulator before the operation and the result is deposited back into it after the operation. All the results carried out by different instructions are stored in the accumulator before and after performance of the operation.

General-purpose registers — B, C, D, E, H, L (6 × 8 bits)

The 8085 has six general-purpose registers, each able to hold an 8-bit value. Their superpower: they combine into three 16-bit pairs — BC, DE and HL — useful for 16-bit data and, above all, for holding 16-bit memory addresses.

Program Counter (PC) — 16 bits

A 16-bit register that always holds the address of the next instruction to be executed. The 8085 fetches the instruction at the address in the PC, then the PC advances automatically; jump, call and return instructions overwrite it to steer the program elsewhere. On reset, the PC starts from zero.

Stack Pointer (SP) — 16 bits

A 16-bit special register that points to the top of the stack — a last-in-first-out (LIFO) region carved out of memory where register contents and return addresses are saved for later use in the program. PUSH drops an item on the stack, POP retrieves it; CALL/RET use it to remember where to come back to. The stack lives in memory, and the SP is the dedicated pointer for all stack operations.

Temporary register — 8 bits

An internal 8-bit register that holds data values during arithmetic and logical operations — typically the second operand while the ALU combines it with the accumulator. It is invisible to the programmer.

Instruction register & decoder — 8 bits

The instruction register is an 8-bit register that holds the instruction code currently being decoded. The instruction is fetched from memory into this register; the instruction decoder then interprets the opcode and tells the timing & control unit exactly what to make the rest of the chip do.

Flag register — 8 bits, 5 flags used

The flag register is a set of flip-flops that automatically record the status of the last ALU result. Five of its eight bit positions are used:

Memory Aid

Flags from MSB to LSB — S · Z · AC · P · CY: “Silly Zebras Always Prefer Cake”. And the register pairs: BC · DE · HL — “Best Computers Do Hard Labour”.

The supporting units

Arithmetic and Logic Unit (ALU)

The computation engine. It performs the mathematical operations — addition, subtraction, multiplication, division, increment, decrement — as well as three families of operations: arithmetic operations, logical operations (AND, OR, XOR, complement, compare) and bit-shifting operations (rotate/shift). It takes its operands from the accumulator and temp register, and reports the outcome to the flag register.

Timing and control unit

The conductor of the orchestra, sitting in the CPU section. It controls the flow of data from the CPU to other devices and coordinates every operation performed by the microprocessor and the devices connected to it. It generates the control signals, DMA signals, RESET signals and status signals, all synchronised to the clock arriving at X1–X2 (the crystal frequency is internally divided by 2, and CLK OUT distributes the resulting system clock to connected devices).

Interrupt control

When the microprocessor is executing the main program and an interrupt suddenly occurs, the microprocessor shifts control from the main program to process the incoming request — it finishes the current instruction, saves the return address on the stack, and jumps to the interrupt service routine. After the request is completed, control goes back to the main program exactly where it left off. The 8085 has five interrupt signals: INTR, TRAP, RST 7.5, RST 6.5 and RST 5.5, in a fixed priority order:

Rank Interrupt Type Vector
1 TRAP Non-maskable highest priority 0024H
2 RST 7.5 Maskable 003CH
3 RST 6.5 Maskable 0034H
4 RST 5.5 Maskable 002CH
5 INTR Maskable lowest priority supplied by device
Memory Aid

Priority order: TRAP is a trap — nothing escapes it (non-maskable, always answered first). Then the restarts simply fall: 7.5 → 6.5 → 5.5, with INTR last in line (lowest priority, and it has no fixed vector — the external device must supply the instruction).

Address bus and data bus

In the 8085, the address bus and data bus are two separate buses used for communication between the microprocessor and external devices. The data bus is bidirectional and carries the data which is to be stored; the address bus is unidirectional and carries the location where data is to be stored.

The clever twist: the lower address byte shares pins with the data bus — lines AD7–AD0 carry the low address byte during the first clock cycle of an operation and the data afterwards. The ALE signal lets external circuitry separate (demultiplex) the two.

Extra

Demultiplexing in practice: an external latch (e.g., the 74LS373) holds the low address byte whenever ALE pulses high; after ALE falls, the same eight wires become the data bus. Combined with A15–A8, the 8085 thus drives a full 16-bit address (64 KB) and an 8-bit data path using only 16 pins.

Serial input/output control

This block controls serial data communication — data moving one bit at a time — between the microprocessor and external devices, via two dedicated lines. SID (serial input data): the data on this line is loaded into the accumulator whenever a RIM instruction is executed. SOD (serial output data): this output is set or reset as specified by the SIM instruction. Two instructions, two lines, one bit at a time.

04

The 8085 Pin Diagram

All 40 pins, organised into 7 functional groups — with an interactive diagram. Tap any group in the legend to isolate its pins.

The 8085 comes in a 40-pin Dual Inline Package (DIP). The pins fall into 7 groups: (1) address bus, (2) data bus, (3) control & status signals, (4) power supply, (5) clock signals, (6) interrupts & externally initiated signals, and (7) serial I/O signals. Learn the diagram below group-by-group rather than pin-by-pin — that is how marks are awarded.

Group 1 — Address bus: A15–A8

These eight lines carry the most significant 8 bits of the memory/IO address. The bus is strictly unidirectional — addresses always flow out of the CPU — and can address 64 KB of memory when combined with the latched lower byte.

Group 2 — Data bus: AD7–AD0

These eight lines carry the least significant 8 bits of the address and the data — time-multiplexed. During the first part of an operation they present the low address byte; afterwards they carry the data itself. Bidirectional, and demultiplexed externally with the help of ALE.

Group 3 — Control & status signals (3 + 3)

These signals are used to identify the nature of the operation in progress. There are three control signals and three status signals.

The three control signals

  • RD (Read): indicates that the selected I/O or memory device is to be read — the device is ready for accepting/making available data on the data bus for the CPU.
  • WR (Write): indicates that the data on the data bus is to be written into a selected memory or I/O location.
  • ALE (Address Latch Enable): a positive-going pulse generated whenever a new operation is started by the microprocessor. When the pulse goes high, AD7–AD0 carry the address (external latches grab it); when the pulse comes down, the same lines carry data.

The three status signals

  • IO/M: differentiates between I/O and memory operations — high = I/O operation, low = memory operation.
  • S1 & S0: used to identify the type of the current operation (opcode fetch, memory read/write, I/O read/write, halt, interrupt acknowledge).
Tbl. 01 — S1 / S0 / IO-M decodingExtra
S1 S0 IO/M Machine cycle
1 1 0 Opcode fetch
1 0 0 Memory read
0 1 0 Memory write
1 0 1 I/O read
0 1 1 I/O write
0 0 Z Halt (buses float)

Group 4 — Power supply: VCC & VSS

Two power supply signals: VCC indicates the +5 V power supply, and VSS indicates the ground signal.

Group 5 — Clock signals: X1, X2, CLK OUT

  • X1, X2: a crystal (or RC / LC network) is connected at these two pins and sets the frequency of the internal clock generator. This frequency is internally divided by 2.
  • CLK OUT: the resulting clock is output here and used as the system clock for devices connected with the microprocessor.

Group 6 — Interrupts & externally initiated signals

Interrupts are the signals generated by external devices to request the microprocessor to perform a task. The five interrupt inputs are TRAP, RST 7.5, RST 6.5, RST 5.5 and INTR (priority covered in Chapter 03). Alongside them live the handshake and reset signals:

  • INTA (Interrupt Acknowledge): the CPU's acknowledgement that an interrupt request has been accepted.
  • RESET IN: used to reset the microprocessor by setting the program counter to zero — the program restarts from address 0000H.
  • RESET OUT: used to reset all the connected devices when the microprocessor itself is being reset.
  • READY: indicates that a device is ready to send or receive data. If READY is low, the CPU has to wait for READY to go high — the standard trick for synchronising slow peripherals.
  • HOLD: indicates that another bus master is requesting the use of the address and data buses (typically a DMA controller).
  • HLDA (HOLD Acknowledge): indicates the CPU has received the HOLD request and will relinquish the buses in the next clock cycle; HLDA goes low after the HOLD signal is removed.
Exam Tip

Examiners single out ALE, IO/M, READY and HOLD/HLDA for one-line definitions. Story to remember them by: ALE separates address from data; IO/M announces the destination type; READY lets slow devices say “wait”; HOLD/HLDA is the polite conversation in which a DMA controller borrows the buses.

Group 7 — Serial I/O signals: SID & SOD

  • SOD (Serial Output Data line): the output is set or reset as specified by the SIM instruction.
  • SID (Serial Input Data line): the data on this line is loaded into the accumulator whenever a RIM instruction is executed.

Together with the serial I/O control block of Chapter 03, these two pins give the 8085 a minimal one-bit-at-a-time channel — enough for simple links to keyboards, displays and other processors without any extra hardware.

05

Types of Microprocessors

Ten families of processing silicon — what each is designed for, and where you've already met it.

Numerous different types of microprocessors are used in computers and devices. For the exam you should be able to name each type and give a one-line description with an example:

RISC
Reduced Instruction Set Computer

A small set of simple, fixed-length instructions — most executing in a single clock cycle. Few addressing modes, hardwired control, heavy use of registers. Fast, cool and power-efficient, which is why it rules mobile and embedded devices.

e.g. ARM / Cortex, Apple M-series, MIPS, SPARC, RISC-V
CISC
Complex Instruction Set Computer

A large instruction set of variable-length, multi-cycle instructions that pack a lot of work into a single instruction (including memory-to-memory operations). Rich addressing modes and microprogrammed control; compact code.

e.g. Intel x86 family (8086 → Pentium → Core), AMD, VAX
Superscalar
Multiple pipelines in parallel

Equipped with multiple execution pipelines, so the processor can issue and complete more than one instruction per clock cycle, exploiting instruction-level parallelism.

e.g. Pentium onwards; every modern high-performance core
ASIC
Application-Specific Integrated Circuit

Not a general-purpose CPU at all — a chip designed for one dedicated task or product, with its function frozen at design time. Massive volumes, tiny unit cost, zero flexibility.

e.g. controller chips in toys, dedicated video/codec engines, mining chips
DSP
Digital Signal Processor

Optimised for high-speed multiply–accumulate maths on streams of samples — audio, video, radio signals. Hardware multipliers and specialised memory access patterns are the hallmark.

e.g. TI C55x/C66x, Qualcomm Hexagon, Analog Devices SHARC
SIMD
Single Instruction, Multiple Data

One instruction operates on many data elements simultaneously — the trick inside multimedia extensions and GPUs for pixel, vector and matrix work.

e.g. MMX / SSE / AVX on x86, ARM NEON
Symbolic
Processors for symbols, not numbers

Designed to manipulate symbols and linked lists rather than numbers — built for artificial intelligence and LISP workloads, with hardware support for tagging and list operations.

e.g. Symbolics LISP-machine processors
Bit-Slice
Cascadeable ALU slices

Built from 2-, 4- or 8-bit “slice” chips cascaded together to construct a processor of any custom word width — the pre-VLSI route to fast, tailor-made computers.

e.g. AMD Am2900 family
Transputer
Transistor + Computer

A 1980s processor with on-chip memory and built-in serial communication links, designed to be tiled by the dozens into massively parallel machines; programmed in the occam language.

e.g. Inmos T414 / T800
GPU
Graphics Processor

Thousands of simple cores in a parallel array, originally built to push pixels, now also the workhorse of parallel computing, machine learning and scientific simulation.

e.g. NVIDIA, AMD Radeon, Intel Arc

06

The Microcontroller

A whole computer on one chip — what it is, what's inside it, its types, and where it hides in your daily life.

Key Fact — Definition

A microcontroller (µC / MCU) is a chip that controls electronic devices — a compact integrated circuit containing a processor, memory and I/O together with supporting devices, designed as a single-chip microcomputer for embedded applications and to govern a specific operation in an embedded system.

Understanding the concept

  • A chip that controls electronic devices — it is present as a single integrated circuit built for embedded applications.
  • It has memory, processor and I/O on the same chip — plus supporting devices such as timers, counters, a serial port and interrupt logic.
  • A system that has a remote controller almost certainly contains a microcontroller.
  • Microcontrollers are single-chip microcomputers, far more suited to the control and automation of machines and processes than general-purpose computing.

Types of microcontrollers

8-BIT
ALU width: 8 bits

The workhorse of simple control tasks — adequate for reading switches, driving relays and running small programs.

e.g. 8051, PIC16F, AVR ATmega, STM8
16-BIT
ALU width: 16 bits

More precision and arithmetic speed for measurement and control loops, often with ultra-low-power designs.

e.g. MSP430, PIC24
32-BIT
ALU width: 32 bits

For heavy applications — networking, displays, audio — where an 8-bit part would struggle.

e.g. ARM Cortex-M (STM32), ESP32
Embedded
All components on-chip

Memory and all peripherals live inside the chip itself — a self-sufficient system needing no external memory ICs.

e.g. 8051 with on-chip mask ROM
External-Memory
Memory lives off-chip

On-chip memory is absent or insufficient, so the controller fetches code/data from external ROM/RAM over its bus.

e.g. 8031 (ROM-less 8051 variant)
Extra

Architecture bonus point: the 8051 uses the Harvard architecture — separate memories and buses for program and data — unlike the von Neumann (Princeton) architecture of classic microprocessors, which keeps one memory for both.

Applications of microcontrollers

Microcontrollers hide inside almost every powered device you own. The syllabus list, plus a few extras:

Mobile phonesAutomobilesCD/DVD playersWashing machinesCamerasSecurity alarmsKeyboard controllersMicrowave ovensWrist watchesMP3 playersRemote controlsSmart cardsIoT edge nodesPrintersToys

Notice the pattern: every item is a single-purpose device that runs one program forever — precisely the job description of a microcontroller.

Microprocessor vs Microcontroller

The single most-asked question from this unit — eleven differences, one picture, and a way to never forget them.

Tbl. 03 — Microprocessor vs Microcontroller (11 points)

1 Centre of a computer system. Centre of an embedded system.
2 Memory and I/O components are external to it. Memory and I/O components are internal to it.
3 Large circuit. Smaller circuit.
4 Not compatible with compact systems. Compatible with compact systems.

6 High power consumption. Low power consumption.

Memory Aid

A microprocessor is a brain missing its body — memory and I/O must be wired to it from outside. A microcontroller is the whole organism on one chip — brain (CPU), memory (ROM/RAM) and limbs (I/O) together. Every table row is just a consequence of that one difference.

The 8051 Microcontroller

Intel's MCS-51 of 1980 — the most-taught microcontroller ever: 40 pins, four ports, and a spec sheet worth memorising.

The Intel MCS-51 — commonly termed the 8051 — is a single-chip microcontroller (MCU) series developed by Intel in 1980 for use in embedded systems. It is a 40-pin Dual Inline Package (DIP) whose pins serve different functions like read, write, I/O operations and interrupts. The 8051 has four I/O ports, each with 8 pins, which can be configured as input or output depending upon the logic state of the pins — 32 programmable I/O lines in total.

Key features of the 8051

On-chip program memory
4 KB ROM — holds the fixed application program
On-chip data memory
128 bytes RAM — variables, register banks and stack
Data bus
8-bit, bidirectional
Address bus
16-bit, unidirectional (→ 64 KB external memory space)
Timers
Two 16-bit timers (Timer 0 and Timer 1)
Instruction cycle
1 µs with a 12 MHz crystal (a machine cycle = 12 clock periods)
I/O ports
Four 8-bit input/output ports — 32 programmable lines
User flags
128 user-definable flags — individually addressable bits in RAM
Extra

Also worth quoting for bonus marks: 4 register banks × 8 registers (R0–R7), one on-chip serial port (UART), five interrupt sources (two external, two timer, one serial), 64 KB external program and 64 KB external data memory spaces, and Harvard architecture (separate program and data memories).

Applications of the 8051

A1
Automation & automotive

Widely used in automotive applications — hybrid vehicles use it to control engine functions, and cruise control and anti-brake mechanisms have been enhanced by microcontroller integration.

A2
Medical devices

Convenient medical devices such as blood-glucose and blood-pressure monitors contain microcontrollers that manage measurement and display the readings.

A3
Energy management

Competent measurement/metering systems calculate energy consumption in home and industrial environments — built by integrating a microcontroller.

A4
Touch screens & portable devices

Many vendors incorporate touch functionality into their designs — portable media players and gaming devices among them.

Uses of the 8051 — where it earns its living

U1
Embedded systems

Home automation, security systems and industrial control — its low cost, small size and ease of programming make it the ideal choice.

U2
Automotive systems

Engine control units, anti-lock braking and airbag systems — controlling functions and ensuring safe, efficient operation.

U3
Robotics

Controlling the movement and operation of robots — motors, sensors and other peripherals.

U4
Consumer electronics

Digital cameras, gaming systems and audio players — driving the user interface, display and other peripherals.

U5
Communication systems

Modems, routers and switches — controlling data transfer and communication protocols.

U6
Medical devices

Insulin pumps, heart monitors and blood-glucose meters — accurate, reliable control and measurement.

U7
Industrial control

Process control systems and manufacturing equipment — monitoring and controlling operations on the factory floor.

Memory Aid

The ports, in one breath: “P0 & P2 are the address duo (low byte & high byte), P3 is the multi-tasker (serial, interrupts, timers, RD/WR) — only P1 is free.” And power pins: “ground before power, bottom before top” — GND at 20, +5 V at 40.

Bus request from another master (e.g., DMA) / the CPU's acknowledgement before releasing the buses.
Interrupt priority
TRAP > RST 7.5 > RST 6.5 > RST 5.5 > INTR.
SID / SOD
Serial input line (read into the accumulator by RIM) / serial output line (set or reset by SIM).
RISC vs CISC
Few, simple, single-cycle instructions vs many, complex, multi-cycle instructions.
Microcontroller
Processor + memory + I/O on a single chip — a single-chip microcomputer for embedded control.
8051
Intel MCS-51 (1980); 40-pin DIP; 4 KB ROM, 128 B RAM, two 16-bit timers, four 8-bit ports.
Port 1
The only 8051 port with no alternate function — internally pulled-up, bidirectional.
PSEN
Program Store Enable — read strobe for external program memory (8051, pin 29).
ALE (8051)
Latches Port 0's low address byte — demultiplexes AD0–AD7 (pin 30).
EA
External Access — low: fetch all code externally; high: run from internal 4 KB ROM first.
Machine cycle (8051)
12 clock periods → 1 µs with a 12 MHz crystal.
128 user flags
The individually addressable RAM bits available to the 8051 programmer.

Model question bank

Each card below is a frequently-asked exam question with a skeleton model answer. Try to answer aloud first, then open to check.

Q1Define a microprocessor and explain its three basic tasks.
  • Definition: a single-IC CPU that performs arithmetic/logic operations, executes instructions and controls data flow — the computer's brain.
  • Task 1: calculations via the ALU (add, subtract, multiply, divide).
  • Task 2: moving data between memory, registers and I/O.
  • Task 3: tracking the Program Counter — the address of the next instruction — and executing sequentially.
  • Close with the fetch–decode–execute cycle.
Q2Draw and explain the block diagram of a microprocessor.
  • CPU contains register array + control unit + ALU (Fig. 02).
  • Address bus: unidirectional, carries locations (16-bit in 8085 → 64 KB).
  • Data bus: bidirectional, carries the data (8-bit).
  • Control bus: RD, WR, ALE, IO/M, interrupts, clock.
  • Memory (ROM/RAM) and I/O devices connect across the system bus as separate chips.
Q3Trace the evolution of microprocessors.
  • 1971 — Intel 4004, 4-bit, first commercial microprocessor (add/subtract on 4 bits only).
  • 1976 — 8085 (8-bit); 1976 — 8086 (16-bit), ancestor of x86; companions 8087 (maths coprocessor) and 8088.
  • 80286 (16-bit) → 80386 (32-bit) → 80486 (on-chip cache).
  • Pentium II → III → IV (superscalar multimedia era).
  • Today: Core 2 Duo, Dual-Core, Quad-Core — multiple cores per chip.
Q4Draw the 8085 architecture and explain its registers.
  • Reproduce Fig. 04: internal 8-bit bus; ALU between accumulator, temp register and flags; IR → decoder → timing & control; interrupt & serial control; address and address/data buffers.
  • ACC (8-bit): operand before / result after operations.
  • B, C, D, E, H, L (6 × 8-bit); pairs BC, DE, HL (16-bit); HL = memory pointer “M”.
  • PC (16-bit): address of next instruction. SP (16-bit): top of stack.
  • Temp register (8-bit): holds data during ALU ops. IR (8-bit) + decoder: opcode storage and interpretation. Flags: S, Z, AC, P, CY.
Q5Explain the 8085 pin diagram, grouped into its seven categories.
  • Address bus A15–A8 (upper address, unidirectional) and data bus AD7–AD0 (multiplexed low address + data, bidirectional).
  • Control: RD, WR, ALE. Status: IO/M, S0, S1 — with one-line meaning of each.
  • Power: VCC (+5 V), VSS (ground). Clock: X1, X2 (crystal, ÷2 internally), CLK OUT.
  • Interrupts & external: TRAP, RST 7.5/6.5/5.5, INTR, INTA, RESET IN/OUT, READY, HOLD, HLDA.
  • Serial: SID (via RIM), SOD (via SIM).
Q6Differentiate between RISC and CISC processors.
  • Instruction set: small/simple vs large/complex; length fixed vs variable.
  • Execution: mostly one cycle vs multiple cycles; addressing modes few vs many.
  • Control: hardwired vs microprogrammed; memory access via load/store only vs many instructions.
  • Examples: ARM, MIPS, RISC-V vs Intel x86, 8086, VAX. (Tbl. 02.)
Q7Distinguish between a microprocessor and a microcontroller (any eight points).
  • Centre of a computer system vs centre of an embedded system.
  • Memory & I/O external vs internal; large vs small circuit; not vs compatible with compact systems.
  • Higher vs lower cost; high vs low power; absent vs present power-saving modes.
  • PCs vs washing machines/music players; fewer vs more registers; CPU-only die vs processor + peripherals die; multi-task vs single repeated program. (Tbl. 03.)
Q8Explain the 8051 pin configuration with alternate functions.
  • 40-pin DIP; four 8-bit ports (P1: 1–8, P3: 10–17, P2: 21–28, P0: 32–39).
  • Pin 9 RESET; pins 18–19 crystal; 20 GND; 40 VCC.
  • Port 3 alternates: RxD, TxD, INT0, INT1, T0, T1, WR, RD (Tbl. 05).
  • Port 2 = A8–A15; Port 0 = AD0–AD7; PSEN (29), ALE (30), EA (31) for external memory control.
Q9List the key features of the 8051 microcontroller.
  • 4 KB on-chip ROM; 128 bytes on-chip RAM.
  • 8-bit bidirectional data bus; 16-bit unidirectional address bus.
  • Two 16-bit timers; four 8-bit I/O ports; 128 user-definable flags.
  • 1 µs instruction cycle with a 12 MHz crystal.
  • Bonus: 4 register banks, UART, 5 interrupt sources, Harvard architecture.
Q10Explain the applications and uses of the 8051 / microcontrollers.
  • Automation: hybrid-vehicle engine control, cruise control, anti-brake mechanisms.
  • Medical: glucose monitors, blood-pressure monitors, insulin pumps, heart monitors.
  • Energy management: consumption metering in homes and industry; touch screens in media players and gaming devices.
  • Uses: embedded systems, automotive, robotics, consumer electronics, communication systems, industrial control — chosen for low cost, small size, easy programming.
